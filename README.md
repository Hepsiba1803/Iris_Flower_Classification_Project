Iris Flower Classification - Machine Learning Project

This project is a beginner-level **machine learning classification model** that predicts the species of iris flowers using the famous **Iris dataset**. It uses the **Random Forest Classifier** to train on sepal and petal measurements and classify the flower into one of three species.

## 📌 Project Overview

- **Objective**: Predict whether a flower is *Setosa*, *Versicolor*, or *Virginica* based on measurements.
- **Algorithm Used**: Random Forest Classifier
- **Dataset**: `sklearn.datasets.load_iris()` (no external file required)

## 🧠 Features Used
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## ✅ Accuracy Achieved
- **100% accuracy** on the test set  
*(Note: This is possible because the Iris dataset is simple and well-separated)*

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Classification Report
- Confusion Matrix (visualized using heatmap)
